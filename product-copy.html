Practical task · Section C

Product copy

To rewrite these properly, I felt it was necessary to find the original context in which they appear. So I had Claude crawl the Koinly help centre to provide context on each. If no context was confirmed, it chose a hypothetical scenario.

  • VerifiedThe error text or screen exists in Koinly’s help centre or support forum. I’ve used the corresponding context.
  • HypotheticalThe error text could not be found in any of Koinly’s resources, so I’ve created a hypothetical rooted in a likely scenario given the error text.

Errors

1Something went wrong. Please try again later.
Context · VerifiedSync and load failures — Koinly’s live string on a failed wallet is “Something went wrong while syncing, try again in a few minutes or contact support,” and “Oops, something went wrong” appears when the Tax Reports page fails to load.
Rewrite

We couldn’t load this page. None of your Koinly data has been changed. Refresh to try again, or contact us if it keeps happening.

WhyThe message names what failed, confirms what’s unaffected, and gives them a way to solve it themselves.
2We couldn’t connect your wallet right now. Your data is safe, just try again in a moment.
Context · VerifiedThe Add Wallet flow, at the moment someone pastes an API key — Koinly’s live string for the common cause is “Access denied” (wrong key permissions).
Rewrite

Coinbase didn’t respond, so your wallet didn’t sync. None of your Koinly data has been changed. We’ll keep trying, or you can resync now.

WhySays which wallet and identifies where the error is. “Your data is safe” is vague and may trigger unwarranted anxiety. Give next steps to follow.

Actions

3Add your transactions below.
Context · HypotheticalThe manual entry screen — where people end up after an integration fails, or for an exchange that no longer exists (Celsius and BlockFi come up constantly in Koinly’s forum).
Rewrite

Add your transactions manually using a spreadsheet and the CSV import tool. You’ll need the date, type, amount and asset. See our guide on manually adding transactions with a CSV for detailed instructions.

WhyThe user has good context at this stage, and has an idea of what is expected of them. It’s up to us to provide them with the next steps so they can self-serve.
4Import your transactions to calculate your taxes accurately.
Context · HypotheticalThe empty state on the Wallets page, first run, nothing connected yet.
Rewrite

Connect your first exchange or wallet. We’ll import your history and start analysing your transactions automatically.

WhyYou import an exchange or wallet account, not individual transactions.

Explanations

5Don’t worry! This happens sometimes.
Context · HypotheticalThe “why did this happen?” detail under a failed wallet on the Wallets page.
Rewrite

Sometimes a connection fails when an exchange is slow to respond. It usually clears when you try again.

WhyReassure the reader by explaining to them what happened, demonstrating it’s not a big deal.
6This can happen if the API connection times out. Reconnecting your wallet should resolve it.
Context · VerifiedThe help centre article or in-app chat, where someone has gone looking after the quick fix didn’t work.
Rewrite

Your exchange account failed to sync due to an API issue. This is typically because:

  • The exchange was slow to respond
  • Your API key has expired

First, resync your wallet. If it fails again, log in to your exchange, create a new API key with read access, and reconnect your account using the new key.

WhyGives explicit instructions on what went wrong, and an additional step to solve it in case it happens again (since it already occurred once). Helps prevent frustration and contacting customer support by providing tools to self-serve.
7The issue is resolved, and your data is now fully synced.
Context · VerifiedThe completion popup after a resync — Koinly shows an “Updating” indicator top-right while it processes, then notifies when it finishes.
Rewrite

Coinbase is connected again. We’ve imported 1,284 new transactions. Check your balances match before you generate a report.

WhyNames the exact issue resolved, and gives a brief summary of what was achieved. Recommends next step.

Warnings

8Missing transactions detected.
Context · VerifiedAgainst an individual transaction on the Transactions page — Koinly’s live string is “Missing purchase history for XYZ”.
Rewrite

We’ve found some transactions that are missing. You will need to resolve these issues before generating a tax report, or else it will be inaccurate. Please visit the “Review” page for more information.

WhyAdds specificity, next steps, and makes it clear this process cannot be skipped.
9We found some transactions that may be missing. Let’s take a quick look so your report stays accurate.
Context · VerifiedThe Tax Summary — the report itself — where Koinly’s live string is “We have assumed a cost of zero for some assets.”
Rewrite

We’ve found some transactions that are missing. You will need to resolve these issues before generating a tax report, or else it will be inaccurate. Please visit the “Review” page for more information.

WhyAdds specificity, next steps, and makes it clear this process cannot be skipped.
Note: I intentionally used the same text for both rewrites in this category, as both of the original error messages appear to convey the same information.

Validation

10Validation failed.
Context · HypotheticalField-level validation in manual transaction or custom price entry.
Rewrite

Your latest transaction contains an error. Please check that the data in the highlighted field is correct.

WhyProvides specificity and next steps.
11Something doesn’t look right yet. Once this is fixed, we can continue with your tax report.
Context · HypotheticalAn error message encountered during CSV import.
Rewrite

When importing transactions manually, they need to be in a CSV file. See our guide on manually importing CSV transactions for more information.

WhyManual CSV transactions are very error prone, as the formatting is specific to each exchange. It’s important to redirect the user to read a dedicated guide on the subject, as it can’t be solved with a short error message.
